# spr-tvc

Attested decryption for Solana Privacy Rings (SPR). A sender can pay a Solana
address before its owner registers a shielded wallet. The owner signs each
decrypt batch. The enclave encrypts the reply to a key generated by the
recipient wallet. The transfer publishes the recipient's Solana address as its
owner tag.

Run `just ci` for Rust and TypeScript checks, including the SDK-to-enclave
loopback test. Run `just headless-e2e` for send, claim, and sweep on localnet.
`gateway` is the decryption gateway: `/v1/decryption/session` and
`/v1/decryption/operations`. `publish-tvc-gateway-image.yml` still publishes
the private-wallet image from the `private-wallet` branch.
