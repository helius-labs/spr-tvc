# Security Invariants & Test Coverage

All tests across every Rust crate and TypeScript package live under `./tests` (zero inline tests in production `src/` files) so security auditors can scope production code independently from test code.

## Running the Suites

- `just ci` — runs all Rust and TypeScript unit, wire, conformance, gateway, and tooling suites.
- `just decryption-e2e` — runs the client examples against the loopback enclave.
- `just headless-e2e` — adds a local validator, indexer, and prover (set `ZOLANA_DIR` if not `../zolana`; pass a port offset for a second localnet).
- Hosted operations live integration tests (ignored/skipped by default unless `SPR_E2E_ENDPOINT`, an API key, and `SPR_E2E_RELEASE_PIN` are set): [hosted_operations.rs](../client/rust/tests/hosted_operations.rs) (`cargo test -p spr-tvc-client --test hosted_operations -- --ignored`) and [hosted-operations.test.ts](../client/sdk/tests/client/hosted-operations.test.ts).

The suites use deterministic fixtures and simulated attestation chains. See the [service spec](../docs/spec.md#key-custody-and-trust) for the trust model governing Quorum operators and release authorities.
