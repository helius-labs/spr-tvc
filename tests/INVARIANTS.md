# Decryption service invariants

Each ID names a guarantee and links to direct assertions. Keep IDs stable.
A recorded rehearsal is distinct from an automated test and applies only to its
recorded configuration. Track uncovered release controls in the [internal audit](AUDIT.md).

## Decryption service

| ID | Invariant | Coverage |
| --- | --- | --- |
| SPR-CORE-01 | Only a canonical, non-identity, prime-order Ed25519 address gets service keys. | Lookup and decrypt reject malformed, off-curve, small-order, mixed-order and noncanonical addresses. Forged, missing, and noncanonical signatures fail even for empty batches. [Owner authorization](../enclave/tests/unit/owner_authorization.rs) |
| SPR-CORE-02 | The address and deployment note seed determine the service keys. | Fixed derivation vectors, address and seed separation, and agreement across replicas. [Derivation](../enclave/tests/unit/key_derivation.rs) · [Release binding](../enclave/tests/unit/release_binding.rs) |
| SPR-CORE-03 | The owner approves the ordered batch for one network and release. | A change to the signer, request ID, item field, item order, item count, network, or response key invalidates approval. | SPR-CORE-04 | Only the signed response key opens the reply. | A second key cannot open the reply or replace the signed key even during a permitted retry. Invalid and compressed response keys fail. [Response privacy](../enclave/tests/unit/response_privacy.rs) |
| SPR-CORE-05 | The enclave uses only the verified signer's viewing key. | An output for another address yields unrelated bytes. | SPR-CORE-06 | Batch and byte limits apply before work crosses the next boundary. | The enclave accepts 256 items, rejects 257, and bounds HTTP bodies and encrypted results. | SPR-CORE-10 | The enclave serializes plaintext replies into one bounded, zeroizing output buffer before encryption. | Both reply variants keep their canonical wire bytes. [Reply encoding](../protocol/tests/unit/decryption_result_encoding.rs) · [Encrypted reply limit](../enclave/tests/unit/app_proof_signature.rs) |
| SPR-CORE-11 | The enclave processes a decrypt only while the signed deadline is in the next 120 seconds by its clock. | Missing, malformed and altered deadlines fail. | SPR-CORE-12 | The TypeScript exchange checks cancellation before decrypting an authenticated reply. | SPR-CORE-13 | Wallet scans discard notes with low-order transaction viewing keys before requesting decryption. | A tagged output with a low-order key never reaches the key holder.
